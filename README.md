# Blimpy

A helium-assisted, camera-equipped AI companion and rotating-dock fleet concept.

This repository collects the engineering work, bench software, CGI marketing-film source, and independent-review brief developed for this project. **FLOAT** is the historical working name used in the films; **Blimpy** is the repository/project name.

## Status

- Engineering results are calculations and software tests, not physical validation.
- Embedded firmware is a bench starter and has not been demonstrated on assembled flight hardware.
- Videos are CGI concept visualizations, not working-prototype footage.
- An independent Opus review was requested and packaged, but **no Opus feedback was obtained**.
- Nothing in this repository establishes flight safety, endurance, manufacturability, or a shipping commitment.
